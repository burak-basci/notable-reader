# beNotable! Reader

This directory is the browser extension beNotable! Reader. It reads web pages, PDFs and e-books aloud with voices
that run on the device; there is no account and no server of its own.

- Privacy: `PRIVACY.md`
- Licenses and third-party components: `tools/reader/LICENSE`, `tools/reader/LICENSE-MIT`,
  `tools/reader/THIRD_PARTY_NOTICES.md`
- Source code, build instructions and issue tracker: https://github.com/burak-basci/notable-reader
- Website: https://reader.benotable.de
